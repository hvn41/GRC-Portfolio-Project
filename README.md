# GRC-Portfolio-Project

# Micro-ISMS: Credential Compromise & Access Governance
This repository contains a micro-portfolio demonstrating the core components of Governance, Risk, and Compliance (GRC). It simulates an organization's structural response to a phishing and credential theft scenario, aligning technical controls with the ISO 27001:2022 framework.

## Project Files
*   **File 1: Access Control Policy** - Defines mandatory MFA and 30-minute session revocation SLAs (Aligned to ISO 27001 Annex A 5.15 & 5.17).
*   **File 2: Risk Assessment** - An ISO 27005-aligned risk matrix quantifying inherent and residual risk for lateral movement and data exfiltration.
*   **File 3: Audit Working Paper** - A simulated compliance audit testing IT response times against the policy SLA, complete with a Corrective Action Plan (CAPA) utilizing SIEM/SOAR automation.
